# Skill Quality Framework

| Criterion | Points |
|---|---:|
| Clarity and usability | 10 |
| Correct scope and triggers | 10 |
| Execution instructions | 15 |
| Input/output contracts | 10 |
| Engineering correctness | 15 |
| Safety and security | 15 |
| Evidence and validation | 10 |
| Handoff and integration | 5 |
| Examples and documentation | 5 |
| Maintainability | 5 |
| Total | 100 |

90–100 is excellent; 80–89 acceptable; 70–79 needs improvement; below 70 is rejected/redesigned. A critical safety failure always fails regardless of numerical score.
