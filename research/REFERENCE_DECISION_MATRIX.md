# Reference Decision Matrix

| Pattern | Decision | Rationale |
|---|---|---|
| Filesystem-based Markdown skills | Adopt | portable and inspectable |
| One skill per micro-stage | Reject | duplicates context and obscures responsibility |
| One monolithic prompt | Reject | lacks progressive disclosure and testability |
| Evidence gates | Adopt | prevents unsupported completion claims |
| Platform-specific source of truth | Reject | creates drift; use canonical registry |
| Copying third-party workflows | Reject | license and fit risk; independently author |
