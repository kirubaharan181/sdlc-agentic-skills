# Tool Integration Catalog

Tool choice is project-specific. For each integration record purpose, supported operations, permissions, configuration, authentication/secret-manager reference, error and rate-limit behavior, security risks, alternatives, compatibility, and testing evidence.

| Domain | Supported options |
|---|---|
| Planning | Jira, Linear, GitHub/GitLab Issues, Azure Boards, Trello, Plane |
| UI/UX | Figma, FigJam, Penpot, Storybook, Playwright |
| Development | Java/Spring, JS/TS/Node, React/Angular/Vue, Python/FastAPI/Django, .NET, Go, PHP, Flutter, React Native |
| Data | PostgreSQL, MySQL, MongoDB, Redis, SQLite, Oracle, SQL Server |
| Testing | JUnit, pytest, Vitest, Jest, Playwright, Cypress, Selenium, Postman/Newman, k6, JMeter, ZAP |
| Security | SonarQube, Semgrep, CodeQL, Snyk, Trivy, Grype, Checkov, Dependency-Check, Gitleaks, TruffleHog |
| Platform | Docker, Kubernetes, Helm, Terraform/OpenTofu, Ansible, Pulumi, Jenkins, Argo CD, Flux, GitHub Actions |
| Cloud/observability | AWS, Azure, GCP, Cloudflare, DigitalOcean, Hetzner; Prometheus, Grafana, OpenTelemetry, Loki, Jaeger, Tempo, ELK/OpenSearch, PagerDuty, Sentry |
| Agents | Claude Code, OpenAI Codex, Gemini CLI, Copilot, Cursor, OpenCode, MCP, LangGraph, CrewAI, AutoGen, n8n |
